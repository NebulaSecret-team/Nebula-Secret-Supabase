數據流向說明
🛒
客戶下單流程
Order Flow
1
客戶瀏覽產品 → 加入購物車
2
填寫結賬信息 → 提交訂單
3
訂單數據寫入 Supabase 數據庫
4
EmailJS 自動發送訂單確認郵件
5
管理員在 Admin Panel 查看訂單
✉️
聯繫表單流程
Contact Flow
1
客戶填寫聯繫表單
2
選擇查詢類型（批發/OEM/ODM 等）
3
提交表單 → EmailJS 發送郵件
4
郵件發送到 sales@nebulasecret.com
5
管理員直接回覆客戶郵箱
⚙️
管理員操作流程
Admin Flow
1
管理員登錄 Admin Panel
2
新增/編輯產品、分類、內容
3
數據實時同步到 Supabase 雲端
4
前台網站立即顯示最新數據
5
所有設備共享同一份雲端數據
🌐
部署更新流程
Deploy Flow
1
修改 index.html 源代碼
2
Commit 到 GitHub main 分支
3
Push 到 GitHub 遠程倉庫
4
Vercel 自動檢測並重新部署
5
1-2 分鐘後網站更新完成
