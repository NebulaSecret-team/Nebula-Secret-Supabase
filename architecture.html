用戶角色與權限
4 種角色
系統包含四種用戶角色，每種角色擁有不同的訪問權限和功能。了解各角色的職責和可訪問的功能模組。
🛍️
訪客 / 客戶
Guest / Customer
瀏覽網站的普通用戶，可查看產品、下單、註冊賬戶。
  • 瀏覽所有產品和分類
  • 使用購物車和結賬功能
  • 註冊和登錄客戶賬戶
  • 查看自己的訂單歷史
  • 提交聯繫表單查詢
  • 切換貨幣和語言
👤
註冊客戶
Registered Customer
已註冊的批發客戶，擁有個人賬戶和訂單管理功能。
  • 所有訪客權限
  • 個人資料管理和修改
  • 密碼修改和重置
  • 完整訂單歷史記錄
  • 訂單狀態實時追蹤
  • 收藏產品和快速下單
🔧
管理員
Admin
網站管理員，可管理產品、訂單、客戶和網站內容。
  • 產品增刪改查和圖片上傳
  • 分類管理和排序調整
  • 訂單查看和狀態更新
  • 訂單數據導出 Excel
  • 客戶賬戶管理和密碼重置
  • 網站內容編輯（Footer/About）
  • 主題顏色和 Banner 設置
  • 郵件服務配置和測試
👑
超級管理員
Super Admin
最高權限管理員，可管理其他管理員和系統配置。
  • 所有管理員權限
  • 新增和刪除管理員賬戶
  • 修改任意管理員密碼
  • 設置管理員角色和權限
  • 查看系統架構頁面
  • 重置所有網站數據
  • 雲端同步配置管理

數據流向與運作流程
了解系統中各個核心流程的運作方式，包括客戶下單、聯繫表單、管理員操作和部署更新。
🛒
客戶下單流程
Order Flow
1
客戶瀏覽產品 → 加入購物車
2
填寫結賬信息 → 提交訂單
3
訂單數據寫入 Supabase 數據庫
4
EmailJS 自動發送訂單確認郵件
5
管理員在 Admin Panel 查看訂單
6
管理員更新訂單狀態 → 客戶可追蹤
✉️
聯繫表單流程
Contact Flow
1
客戶填寫聯繫表單
2
選擇查詢類型（批發/OEM/ODM 等）
3
提交表單 → EmailJS 發送郵件
4
郵件發送到 sales@nebulasecret.com
5
同時發送到 bong8686@gmail.com
6
管理員直接回覆客戶郵箱
⚙️
管理員操作流程
Admin Flow
1
管理員登錄 Admin Panel
2
新增/編輯產品、分類、內容
3
數據實時同步到 Supabase 雲端
4
前台網站立即顯示最新數據
5
所有設備共享同一份雲端數據
6
管理員可導出訂單 Excel 報表
🌐
部署更新流程
Deploy Flow
1
修改 index.html 源代碼
2
Commit 到 GitHub main 分支
3
Push 到 GitHub 遠程倉庫
4
Vercel 自動檢測並重新部署
5
1-2 分鐘後網站更新完成
6
全球 CDN 節點同步更新
