用戶角色與權限
4 種角色
系統包含四種用戶角色，每種角色擁有不同的訪問權限和功能。客戶分級定價系統根據客戶級別自動應用不同折扣。
🛍️
訪客 / 新客戶
Guest / New Customer
瀏覽網站的普通用戶，可查看產品、下單、註冊賬戶。默認級別：New Customer（0% 折扣）。
  • 瀏覽所有產品和分類（標準批發價）
  • 使用購物車和結賬功能
  • 註冊和登錄客戶賬戶
  • 提交聯繫表單查詢
  • 切換貨幣（18 種）
  • 請求產品報價
👤
註冊客戶
Registered Customer
已註冊的批發客戶，擁有個人賬戶和訂單管理功能。可設置客戶級別享受折扣。
  • 所有訪客權限
  • 客戶級別定價（Regular 5% / VIP 10%）
  • 個人資料管理和密碼修改
  • 完整訂單歷史記錄和 PDF 下載
  • 訂單狀態實時追蹤
  • 報價請求和管理
🔧
管理員
Admin
網站管理員，可管理產品、訂單、客戶、報價和網站內容。
  • 產品增刪改查和圖片上傳
  • 分類管理和排序調整
  • 訂單查看、狀態更新、Excel 導出
  • 報價管理（接受/拒絕/修改價格）
  • 客戶賬戶管理和級別設置
  • 客戶分級定價管理
  • 網站內容編輯（Footer/About）
  • 主題顏色和 Banner 設置
👑
超級管理員
Super Admin
最高權限管理員，可管理其他管理員和系統配置。
  • 所有管理員權限
  • 新增和刪除管理員賬戶
  • 修改任意管理員密碼
  • 查看系統架構頁面
  • 郵件服務配置和測試
  • 雲端數據同步管理

客戶分級定價系統
3 個級別
客戶分級定價系統自動根據客戶級別應用不同折扣。管理員可在 Admin Panel 設置客戶級別，客戶登錄後自動看到對應級別的折扣價格。
🆕
New Customer
新客戶 · 0% 折扣
新註冊客戶的默認級別，享受標準批發價格。
標準批發價
0% OFF
🔵
Regular Customer
普通客戶 · 5% 折扣
回頭客或穩定合作客戶，享受 5% 批量折扣。
批量優惠價
5% OFF
👑
VIP Customer
VIP 客戶 · 10% 折扣
重要合作夥伴和大客戶，享受最高 10% 專屬折扣。
VIP 專屬價
10% OFF
💡 工作原理：客戶登錄後，系統自動識別其級別並在產品列表、產品詳情頁、購物車中應用對應折扣。管理員可在 Admin Panel → Customer Tiers 管理級別，在 Customer Accounts 為每個客戶設置級別。

數據流向與運作流程
了解系統中各個核心流程的運作方式，包括客戶下單、報價請求、聯繫表單、管理員操作和部署更新。
🛒
客戶下單流程
Order Flow
1
客戶瀏覽產品（自動應用分級折扣）→ 加入購物車
2
填寫結賬信息 → 提交訂單
3
訂單數據寫入 Supabase 數據庫
4
Vercel Edge Function → EmailJS 發送確認郵件
5
管理員在 Admin Panel 查看訂單
6
管理員更新訂單狀態 → 客戶可追蹤
💰
報價請求流程
Quote Flow
1
客戶在購物車點擊 "Request Quote"
2
填寫目標價格和期望交貨日期
3
報價請求寫入 Supabase 數據庫
4
管理員在 Admin Panel 查看報價
5
管理員接受/拒絕/修改價格
6
客戶在賬戶頁面查看報價狀態
✉️
聯繫表單流程
Contact Flow
1
客戶填寫聯繫表單
2
選擇查詢類型（批發/OEM/ODM 等）
3
提交表單 → Vercel Edge Function
4
Edge Function 調用 EmailJS API
5
郵件發送到 sales@nebulasecret.com
6
同時發送到 bong8686@gmail.com
⚙️
管理員操作流程
Admin Flow
1
管理員登錄 Admin Panel（Supabase Auth）
2
新增/編輯產品、分類、內容
3
設置客戶級別和折扣
4
數據實時同步到 Supabase 雲端
5
前台網站立即顯示最新數據
6
所有設備共享同一份雲端數據
🌐
部署更新流程
Deploy Flow
1
修改 index.html / admin.js 源代碼
2
Commit 到 GitHub uat 分支（測試）
3
Vercel 自動部署到 UAT 環境
4
在 uat.nebulasecret.com 測試
5
測試通過後合併到 main 分支
6
Vercel 自動部署到 Production 環境

分級定價流程
Tier Pricing Flow
1
管理員在 Customer Tiers 設置級別和折扣
2
管理員在 Customer Accounts 為客戶設置級別
3
客戶登錄賬戶
