嚴重 管理員密碼硬編碼在源代碼中
已修復 ▼
問題描述

管理員登錄密碼 abcd1234 直接硬編碼在 HTML 源代碼中，任何人查看網頁源代碼即可獲取管理員密碼，從而完全控制網站後台。

風險評估
  • 影響範圍：完全控制網站後台，可修改產品、查看訂單、管理用戶
  • 利用難度：極低，只需右鍵查看網頁源代碼
  • 潛在損失：數據泄露、網站被篡改、商業機密泄露
修復方案
  • 遷移到 Supabase Auth 進行管理員認證
  • 密碼存儲在 Supabase 後端，不在前端代碼中暴露
  • 使用 PBKDF2 算法進行密碼哈希（100,000 次迭代）
  • 移除源代碼中所有硬編碼的密碼
修復狀態

✅ 已完全修復 - 管理員認證已遷移到 Supabase Auth，源代碼中不再包含任何密碼。

嚴重 EmailJS 配置信息（含 API Key）暴露在源代碼中
已修復 ▼
問題描述

EmailJS 的 Service ID、Template ID 和 Public Key 直接硬編碼在源代碼中，攻擊者可以盜用這些配置發送垃圾郵件，消耗你的免費額度（每月 200 封）。

風險評估
  • 影響範圍：郵件服務被濫用，免費額度被消耗
  • 利用難度：低，查看源代碼即可獲取配置
  • 潛在損失：無法接收客戶訂單和聯繫請求，商務損失
修復方案
  • EmailJS 配置改由管理員在 Admin Panel → Order Emails 頁面設置
  • 配置存儲在瀏覽器的 localStorage 中，不硬編碼在源代碼
  • 添加發送頻率限制：每分鐘 5 封、每小時 20 封、每天 100 封
  • 添加域名驗證：只允許從授權域名發送
  • 添加 SRI 校驗：EmailJS 庫加載時驗證完整性
修復狀態

✅ 已完全修復 - EmailJS 配置不再硬編碼，已添加多層安全保護。

高 跨站腳本攻擊 (XSS) 漏洞
已修復 ▼
問題描述

用戶輸入的內容（如聯繫表單、產品評論等）未經過濾直接渲染到頁面上，攻擊者可以注入惡意 JavaScript 代碼，竊取用戶 Cookie 或執行未授權操作。

修復方案
  • 添加 sanitizeHTML() 函數，對所有用戶輸入進行 HTML 轉義
  • 使用 textContent 代替 innerHTML 渲染用戶輸入
  • 對所有動態生成的 HTML 內容進行過濾
  • 添加內容安全策略 (CSP) 響應頭
修復狀態

✅ 已完全修復 - 所有用戶輸入均經過 sanitizeHTML() 過濾。

高 敏感信息輸出到控制台 (Console)
已修復 ▼
問題描述

調試代碼中的 console.log() 語句輸出了敏感信息，包括用戶密碼、API Key、數據庫查詢結果等，這些信息可以在瀏覽器開發者工具中被任何人查看。

修復方案
  • 移除所有輸出敏感信息的 console.log() 語句
  • 保留必要的錯誤日誌，但不包含敏感數據
  • 添加生產環境檢測，生產環境自動禁用 console 輸出
修復狀態

✅ 已完全修復 - 所有敏感信息的 console 輸出已移除。

高 個人郵箱地址硬編碼在源代碼中
已修復 ▼
問題描述

個人郵箱地址（如 bong8686@gmail.com）直接硬編碼在源代碼中，不僅暴露了個人隱私，還容易被爬蟲收集用於發送垃圾郵件。

修復方案
  • 移除源代碼中所有硬編碼的個人郵箱地址
  • 郵件收件人改由管理員在 Admin Panel 配置
  • 使用企業郵箱（sales@nebulasecret.com）代替個人郵箱
  • 對頁面上顯示的郵箱地址進行混淆處理
修復狀態

✅ 已完全修復 - 個人郵箱已從源代碼中移除。

中 管理員後台代碼與前端代碼混合
已修復 ▼
問題描述

管理員後台的 JavaScript 代碼與前端頁面代碼混合在同一個文件中，即使未登錄管理員，這些代碼也會被加載到瀏覽器中，增加了攻擊面和代碼泄露風險。

修復方案
  • 管理員代碼分離到獨立的 admin.js 文件
  • 採用懶加載策略，僅在用戶訪問 /admin 路徑時才加載
  • 管理員頁面加載前先驗證用戶身份
  • 減小前端頁面的代碼體積，提高加載速度
修復狀態

✅ 已完全修復 - 管理員代碼已分離並採用懶加載。

中 GitHub Token 硬編碼在源代碼中
已修復 ▼
問題描述

用於 Cloud Sync 功能的 GitHub Personal Access Token 直接硬編碼在源代碼中，攻擊者可以利用這個 Token 訪問你的 GitHub 倉庫，讀取或修改代碼。

修復方案
  • 移除源代碼中所有硬編碼的 GitHub Token
  • Token 改由管理員在 Admin Panel 輸入，存儲在 localStorage
  • 棄用舊的 Token，在 GitHub 後台重新生成新 Token
  • 使用細粒度權限 Token (Fine-grained Token)，只授予必要的權限
修復狀態

✅ 已完全修復 - GitHub Token 已從源代碼中移除。

中 密碼哈希算法強度不足
已修復 ▼
問題描述

用戶密碼使用 SHA-256 算法進行哈希，雖然比明文存儲安全，但 SHA-256 是快速哈希算法，容易被暴力破解或彩虹表攻擊。

修復方案
  • 升級到 PBKDF2 算法（Password-Based Key Derivation Function 2）
  • 設置 100,000 次迭代，大幅增加破解成本
  • 使用隨機鹽值 (Salt)，防止彩虹表攻擊
  • 符合 OWASP 密碼存儲最佳實踐
修復狀態

✅ 已完全修復 - 密碼哈希已升級為 PBKDF2（100,000 次迭代）。

中 缺少 .gitignore 配置，敏感文件可能被提交
已修復 ▼
問題描述

項目中缺少 .gitignore 文件或配置不完善，包含敏感信息的文件（如 .env 環境變量文件）可能被意外提交到 GitHub 公開倉庫，導致 API Key、數據庫密碼等敏感信息泄露。

修復方案
  • 創建完善的 .gitignore 文件
  • 添加環境變量文件：.env、.env*.local
  • 添加操作系統文件：.DS_Store、Thumbs.db
  • 添加編輯器配置：.vscode/、.idea/
  • 添加依賴目錄：node_modules/
  • 添加構建產物：dist/、build/
修復狀態

✅ 已完全修復 - .gitignore 已配置完善。

低 CDN 依賴缺少完整性校驗 (SRI)
已修復 ▼
問題描述

從 CDN 加載的第三方 JavaScript 庫（如 EmailJS）缺少 Subresource Integrity (SRI) 校驗，如果 CDN 被攻擊或 DNS 被劫持，攻擊者可以替換腳本內容，注入惡意代碼。

修復方案
  • 為所有 CDN 加載的腳本添加 integrity 屬性（SRI 哈希）
  • 添加 crossorigin="anonymous" 屬性
  • 瀏覽器會自動驗證腳本完整性，不匹配則拒絕執行
  • 使用固定版本的 CDN 鏈接，避免使用 latest 標籤
修復狀態

✅ 已完全修復 - 所有 CDN 腳本已添加 SRI 校驗。

低 缺少 HTTPS 強制跳轉
已修復 ▼
問題描述

網站沒有強制使用 HTTPS，用戶可能通過不安全的 HTTP 協議訪問網站，導致數據在傳輸過程中被竊聽或篡改。

修復方案
  • 利用 Vercel 平台的自動 HTTPS 功能，所有站點默認啟用 SSL/TLS
  • 配置自動 HTTP → HTTPS 跳轉
  • 添加 HSTS (HTTP Strict Transport Security) 響應頭
  • 所有外部資源鏈接使用 HTTPS 協議
修復狀態

✅ 已完全修復 - Vercel 平台自動提供 HTTPS 和強制跳轉。

低 表單輸入缺少驗證和淨化
已修復 ▼
問題描述

聯繫表單和結賬表單的用戶輸入缺少前端驗證，用戶可以輸入無效的郵箱地址、電話號碼，或提交空表單，影響數據質量和用戶體驗。

修復方案
  • 添加前端表單驗證：必填字段、郵箱格式、電話號碼格式
  • 實時驗證反饋，用戶輸入時即時顯示驗證結果
  • 對所有用戶輸入進行 trim 和淨化處理
  • 限制輸入長度，防止超长輸入攻擊
  • 友好的錯誤提示，指導用戶正確填寫
修復狀態

✅ 已完全修復 - 所有表單已添加驗證和淨化。

💡 進一步安全建議 (Additional Security Recommendations)

以下是可選的進一步安全增強建議，根據業務需求和預算情況選擇實施。

高優先級

升級 EmailJS 付費計劃

開啟域名白名單功能，只允許從你的域名發送郵件，即使 API Key 被盜也無法濫用。費用：$9/月起。

高優先級

添加 Google reCAPTCHA

在聯繫表單和訂單頁面添加人機驗證，有效防止機器人濫用。完全免費，不影響正常用戶體驗。

中優先級

配置 Cloudflare CDN

使用 Cloudflare 免費計劃，提供 DDoS 保護、WAF（Web 應用防火牆）、自動 HTTPS 升級和 CDN 加速。

中優先級

啟用 Supabase 項目喚醒

配置定時任務（如每 6 天訪問一次網站），防止 Supabase 免費項目因 7 天無活動而進入休眠狀態。

低優先級

定期安全審計

每季度進行一次安全審計，檢查依賴庫更新、掃描漏洞、審核日誌，保持網站安全狀態。

低優先級

數據備份策略

配置 Supabase 數據庫自動備份，定期導出訂單和用戶數據，防止數據丟失。
